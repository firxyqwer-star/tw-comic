# 漫画工作台

把一条酒馆角色回复改编成多页漫画。分镜规划复用酒馆当前连接的模型；图片可交给 ComfyUI、NovelAI 或 SD WebUI。

## 制作流程

- **准备**：编辑待改编正文、勾选资料来源、核对人物名单并规划分页。「绘图后端」用于配置出图服务，「画风与工具」提供画风、备份和酒馆状态检查。
- **分镜**：按页查看分格、画面和对白。要直接修改分镜数据时，展开「高级编辑」，编辑后保存。
- **出图**：通过缩略图切换单页预览，可逐页重画或批量生成。关闭出图预览后，点原消息旁的生成进度即可回来继续查看或停止。

## 角色卡人物缓存

读取人物资料或规划时，漫画插件会把能识别的基础外貌存入目标角色卡的扩展字段。柏宝书只保存名册人物的基本描述；世界书只从带有明确外貌标记的人物条目取信息。同一张卡换聊天后仍可自动复用，新的资料或本轮明确变化优先。群聊只在能唯一定位发言角色卡时写入。关闭来源时也会跳过该来源的缓存。

通过酒馆扩展管理器卸载时会删除本机角色卡中的漫画人物缓存字段；也可通过“清理扩展数据”先清除缓存。停用插件可保留缓存。已导出的角色卡副本或手动删除插件目录不经过酒馆的卸载流程。

## 人物资料和画风

扩展设置中新增两个独立开关，默认均开启，可分别关闭并保存；每次漫画预览也能覆盖本次选择：

- **读取柏宝书资料**：针对已安装1.1.6的公开API v1，只消费“角色”名册 `npcs` 的姓名、性别、年龄、身份、固定外貌 `desc`、当前穿着与身体状态，以及聊天/时点/覆盖元信息。不读取或使用柏宝书主角档案、历史摘要、物品、变量、场景、计划。不触发补摘、总结，不写回任何记忆。
- **读取世界书资料**：只读取当前角色/群组角色、聊天和全局绑定书，筛选启用且与本轮文字、人物姓名或关键字匹配的条目。不会扫描未关联书，不执行宏或原生世界书触发器。该筛选是漫画资料检索，不代表酒馆原生触发条件已满足。

关闭后不访问对应来源，也不复用先前读取结果；关闭不会删除历史分镜中已经整理的人物描述。新规划始终按当前开关重新取资料。

两项关闭时仍可使用待改编正文、目标消息之前最近6条非系统消息、当前发言角色卡说明和手动人物补充。不会读取目标消息之后的聊天正文。柏宝书名册按目标楼层前后读取，分开标注，避免把本轮结束时的换装/伤势提前到开头。未匹配到角色时，可以在人物补充里写明姓名后重读。旧聊天关联的世界书若已变更，检索使用的是当前书内容，不是历史世界书快照。

预览里的 **“读取人物资料”** 不调用模型，只展示来源、角色资料、覆盖缺口和预算截断。规划时会重新读取，并把所选资料作为数据提交给当前规划模型。模型产生的人物设定、来源回执和缺失/冲突说明只保存在本扩展的消息记录中。资料读取不意味着人物辨识完全准确，需检查分镜的人物说明。

总资料正文预算28000字符；前文最多6条、每条2000字符，当前角色卡说明4000字符；柏宝书相关NPC前后各最多12名、每字段1000字符；世界书最多8本、24条，每条3000字符。预算不足时明确提示。这里只是长度限制，不等同模型token上限。

当前默认采用**英文细化版现代日系幻想手游角色插画风**，强调轻薄的彩色轮廓、银蓝发丝高光和冷暖渐变。人物特征、服装和场景仍由资料与分镜决定。旧的内置默认设置会自动升级，用户自定义画风保留。

本次未接入参考图或编辑LoRA，文字人物描述更完整也不能保证模型跨页完全同脸。建议先查看资料，再规划并核对人物说明，最后自行决定是否重画。

## 使用

1. 在漫画工作台的「准备 → 绘图后端」选择并配置出图服务。分镜默认输出上限为 12000 token，受当前模型实际支持范围限制。
2. 在一条角色消息旁点击“生成多页漫画”。检查待改编正文；如果消息含状态栏、变量更新或脚本，请删去本次不需要画出的部分，这不会修改原消息。
3. 填写人物外观与画风，点击“规划分页”。正文会发送给你此时在酒馆中使用的模型服务；这一次调用产生额外用量。规划期间请等待结束后再继续角色对话。
4. 检查多页分镜、对白和人物状态。引号对白有遗漏时会提示，但未提示不代表完全保真。分页编号覆盖检查不等于语义检查。
5. 可以直接修改分镜 JSON，再点“保存分镜修改”；这会重建各页生图提示词，已有同页图片保留并标记待重画。修改单页提示词后可以保存或重画；保存单页提示词本身不会重画。
6. 点击“生成未完成页”，按顺序提交尚未完成或分镜已修改的页面。也可单独生成、重画某页。失败时队列暂停，成功页面保留；再次点击可续跑。
7. 图片在对应消息下方折叠显示，点击图片打开原图。“下载分镜备份”导出分镜、提示词和图片路径，**不打包图片文件**。

模型直接绘制对白与气泡，可能错字、漏字或改变分格；查看图片后可以改提示词重画。本版未实现程序排字，不承诺跨页人物完全一致。

## 安装和配置绘图后端

在酒馆顶部打开「扩展 → 安装扩展」，粘贴本仓库的 HTTPS Git URL（仓库页「Code → HTTPS」中的地址），安装后重新加载酒馆。在扩展设置中可以找到「漫画工作台」，在角色回复旁点击「生成多页漫画」即可打开工作台。

手动安装时，解压后将 `tw-comic` 文件夹放到酒馆第三方扩展目录，确认 `manifest.json` 在该文件夹第一层。

从角色回复打开漫画工作台，在「准备」页展开「绘图后端」。新安装默认关闭绘图，仍可规划分镜和查看已有漫画。

- **NovelAI**：在工作台填写「NovelAI API 密钥」，点「保存 NovelAI 密钥」。密钥会保存到酒馆并成为当前使用的 NovelAI 密钥，已在酒馆保存过可留空。点「测试连接」查询订阅状态，再点「保存绘图设置」启用该后端及所选模型。默认模型为 `nai-diffusion-4-5-full`，每页输出 832 × 1216。实际生成可能消耗额度。
- **SD WebUI**：用 `--api` 启动服务，填写酒馆后端可访问的地址并保存，例如同机的 `http://127.0.0.1:7860`。使用 WebUI 当前加载的模型，每页输出 768 × 1344。当前支持可直接访问的标准 SD WebUI API。
- **ComfyUI**：可使用自定义工作流，按下面的步骤配置。

### 配置 ComfyUI

1. 选择 **ComfyUI**。
2. 填写**酒馆后端**能访问的 ComfyUI 服务地址。两个服务在同一台电脑时可填 `http://127.0.0.1:8188`。如果运行在不同设备或容器，填写酒馆后端实际能访问的地址。点击「测试连接」检查服务是否可达。
3. 可导入 [MOSS 25 步 API 工作流](workflows/moss-25-api.json)，或在 ComfyUI 中导出自己的 **API 格式**工作流后导入。导入入口是「准备 → 绘图后端 → ComfyUI → 选择 API 工作流文件」，也可粘贴 JSON。
4. 在「每页提示词」中选择正向文本节点的输入，例如 `CLIPTextEncode → text`。随机种子和文件名前缀可以绑定，也可以保留工作流原值。已有的 `%prompt%`、`%seed%`、`%filename_prefix%` 整值占位符会自动识别。
5. 确认工作流有图片输出，而且 ComfyUI 已装好所需节点和模型。点击「保存绘图设置」后，可以用一页分镜验证实际出图和回显。「测试连接」只检查服务是否可达。

升级时保留旧地址和自定义工作流。新安装要手动选择适合自己模型的工作流后保存。

### 随附工作流的出处和测试模型

`workflows/moss-25-api.json` 取自黑鹤001 的「▶MOSS-Image-生图流（整合）」中用于出图的 25 步分支，并整理为适用于 SillyTavern / TauriTavern「漫画工作台」的 ComfyUI API 格式。插件会自动替换每页提示词、随机种子和图片文件名前缀。该文件输出一张 9:16 竖版漫画页，保留原分支的 25 步采样参数。[黑鹤001 的 B 站原视频，2026 年 10 月 24 日](https://www.bilibili.com/video/BV1a5HN69ENF/)

| 用途 | 本地测试使用的文件名 |
| --- | --- |
| MOSS-Image 主模型 | `Moss-大师pornmasterMoss_v1_int8_convrot.safetensors` |
| Qwen 文本编码器 | `qwen3.5_9b_w4a8_gptq.safetensors` |
| VAE | `flux2-vae_small.safetensors` |

仓库提供 API 工作流 JSON，模型权重和自定义节点需在 ComfyUI 中自行安装。模型所在子目录不同的话，在 API JSON 中调整 `unet_name`、`clip_name` 或 `vae_name`，再导入酒馆。原始 ComfyUI 画布版请从作者视频获取。

绘图请求由酒馆后端代发。不同绘图模型对分格、长提示词和中文对白的表现会有差异。

## 保存与停止

分镜和图片路径保存在原消息的 `extra.tw_comic`，按正文和回复分支分别匹配；修改原正文后旧结果不会错误挂到新正文上。图片通过酒馆保存接口保存在酒馆图片目录。跨设备迁移需要同时迁移聊天和图片，单独分镜 JSON 没有恢复图片的能力。

出图期间关闭漫画预览，插件会继续生成并保存后续页。重新打开同一消息的预览可查看进度。点「停止生成」后，当前已提交的页会完成并保存，未提交的页留待续跑。刷新或退出酒馆会结束客户端队列，切换聊天或回复分支会停止后续页。规划阶段关闭预览会停止接收规划结果。
